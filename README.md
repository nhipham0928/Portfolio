# 🪐 Nhi's Portfolio — Orbit & Celestial Space
> *"Destined with Physics, crafting logic through code, and fine-tuning signals at Bosch."*

Portfolio cá nhân của **Phạm Thị Yến Nhi** — không gian lưu trữ các dự án nghiên cứu, lập trình và sở thích cá nhân.
🔗 **Live Demo:** [portfolio-nhipham0928.vercel.app](https://portfolio-nhipham0928.vercel.app/)


### ✨ Features
- 🌌 **Dual Theme:** Dark Mode (Bầu trời sao đêm & sao băng qua HTML5 Canvas) & Light Mode (Nền Frost Blue mát dịu).
- 🖼️ **Fluid Water-Blob Slider:** Hiệu ứng khung ảnh uốn lượn morphing lướt từng ảnh.
- 🎵 **Interactive Audio:** Tự động phát nhạc thư giãn khi mở tab Music, ngắt nhạc khi rời khu vực.
- 📱 **Responsive & High Contrast:** Tối ưu hiển thị đa thiết bị, tương phản cao, dễ đọc.
- 📬 **Contact Form:** Gửi tin nhắn trực tiếp qua Formspree.
  

### 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6+)
- **Graphics:** HTML5 Canvas API
- **Fonts:** Cinzel & Montserrat
- **Deploy:** Vercel
